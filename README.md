# Sukuna X Music

Telegram radio streaming starter project.

See [SETUP.md](SETUP.md) and [START.md](START.md) before deploying. This project uses a direct audio stream URL and attempts to play it in an already-active Telegram group voice chat.

**Note:** Telegram voice-chat streaming support depends on PyTgCalls version and account/session configuration. If the stream fails to join or play, check the current PyTgCalls documentation and Render logs.
